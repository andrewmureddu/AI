# Essays

The rest of this repository is deliberately dry: ladders, falsifiers, ledgers.
That dryness is a discipline, and the discipline works. But the project keeps
generating questions the ledger format cannot hold — questions about what an
invariant *is*, why the same object keeps turning up, and what kind of inquiry
this even is. Those questions deserve prose, and prose that is allowed to argue.

These essays are the pressure valve. They are **philosophy grounded in the
repo's own results** — every essay cites the derivations and experiments it
leans on — but they are explicitly *not* entries in the map. Nothing here has a
ladder level. An essay can be wrong in ways the catalog is not allowed to be.

## Ground rules

- **Cite the ledger.** Claims about what "we found" link to the actual
  derivation or experiment. Speculation is fine; laundering speculation as
  result is not — the same rule as everywhere else in the repo.
- **Tag the register.** Where an essay shifts from reporting to conjecture, it
  says so, in the spirit of the 🟢/🟡/🔴 tiering in
  [`PREDICTION-FIELD.md`](../PREDICTION-FIELD.md).
- **Essays don't graduate.** If an essay's conjecture becomes testable, the test
  goes in `experiments/` or `questions/` and the essay links to it. The essay
  itself stays an essay.
