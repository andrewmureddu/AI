# Research log

Dated, append-only record of what was investigated and decided. One file per entry,
named `YYYY-MM-DD-<slug>.md`. Newest listed first below.

The log is where level/status *changes* get their justification. If you promote,
demote, or add an invariant, there should be a log entry explaining why. This keeps
the map honest and reconstructable.
