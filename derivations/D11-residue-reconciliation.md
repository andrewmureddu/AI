# D11 — the residue reconciled: one structure, three descriptions

**Tests:** [D11](../questions/UNKNOWN-LAWS.md), flagged in
[`SYNTHESIS.md`](../SYNTHESIS.md) §7.0(iii) as the register's next question after
branch reconciliation: three independently-produced accounts of "what the
residue is in general" — [D7/D8](./D7-the-residue.md)'s projective ray /
Grassmannian point, [D10](./D10-composition-lens.md)'s composition-pinning
criterion, and [D3-ladder-invariance](../experiments/D3-ladder-invariance/)'s
"fixed point of the description map, ratio as eigenvalue" — produced on three
branches none aware of the others, and never checked against each other.

**Result: they are not three competing definitions. They are three facets of
one textbook structure — a description map's linearization at a fixed point —
recovered independently because none of the three sessions had all of D2, D6,
P-D, D7, D8 and D10 in view at once.** D7/D8 compute the *projectivized
eigenvalue data* of that linearization from observable log-slopes. D10 states
*which variables carry an eigenvalue structure at all* (the pinning criterion:
additive-under-composition variables have canonical charts, and their bare
exponents are facts rather than gauge). D3's "fixed point" language is the
literature's own name for what D7/D8 are eigenvalues *of*. The residue is
therefore: **the projectivized spectrum of the linearized description map at a
fixed point, on whichever variables the composition law leaves free to
re-chart.**

**What this adds beyond restating the three.** A proved, not merely observed,
boundary: the residue is blind to exactly the directions **tangent to the
fixed-point set** — a marginal/moduli direction in RG language — and this is
provable in closed form for an explicit, infinite-dimensional family, not just
demonstrated once by accident (as D3's lognormal-mixture counterexample was).
Numerics: [`experiments/D11-residue-reconciliation/`](../experiments/D11-residue-reconciliation/).

**Boundary, stated before the numbers:** this is checked in the setting D7, D8
and D3-ladder-invariance already share — a single control (aggregation count),
one description map (renormalized convolution). It is not checked for D8's
multi-control Grassmannian case, nor for a description map with genuine
non-trivial dynamics (an interacting RG flow, not a linear/exactly-solvable
one). Both are named as the obvious next tests and neither is run here.

---

## 1. Setup: description maps, fixed points, linearization

A **description map** is an operator T on a space of systems 𝒮 (laws, coupling
vectors, whatever a domain supplies), with a fixed point (or fixed-point *set*)
x* ∈ 𝒮 satisfying T(x*) = x*. An **approach** is a family of systems x(ε) ∈ 𝒮
reaching x* as a control ε → 0, or generated discretely by repeated application
of T (a level index N, or a repeated-aggregation count n, playing the role of
1/ε — [D7](./D7-the-residue.md) §1 already treats the continuous and discrete
cases identically, and nothing here needs to redo that).

Near x*, to the order that governs leading scaling behaviour, the approach is
controlled by the **linearization** DT(x*): a linear operator on the tangent
space at x*, whose eigenvalues split by the usual classification — **relevant**
(|λ| > 1 in the "one RG step" normalization, growing under repeated T),
**irrelevant** (|λ| < 1, shrinking), **marginal** (|λ| = 1 to linear order,
neither, and requiring a nonlinear analysis to resolve).

This is not new content. It is the definition every renormalization-group
textbook uses (Wilson, Kadanoff, Wegner), already the prior-art basis
[D2](./D2-gauge-of-the-tower.md) cited for its own G_diff/G_pow distinction.
What follows is stating, precisely, that this is what D7/D8/D10/D3 were each
independently describing a piece of.

## 2. C1 — the residue is the projectivized eigenvalue vector (identity, given D7's hypotheses)

Suppose the family x(ε) is generated by repeated application of T along an
eigendirection (or a combination of eigendirections) of DT(x*) — the standard
RG picture, where a perturbation x* + ε·v flows as T^N(x* + ε·v) ≈
x* + ε·λ^N·v for v an eigenvector with eigenvalue λ. An observable O_i that is,
to leading order, a linear functional of the perturbation along an
eigendirection with eigenvalue λ_i acquires

```
        O_i(ε)  ~  ε^{x_i},      x_i  =  ln λ_i / ln b
```

where b is the map's own rescaling factor per application (D7's discrete-chart
case: b is the coarse-graining factor; the continuous case folds b into the
definition of ε). This is the standard scaling-exponent formula, and it is
exactly [D2](./D2-gauge-of-the-tower.md)'s R1–R3 legs: an RG eigenvalue y and a
critical exponent are the same number read two ways.

D7 §2's lemma — re-charting ε ↦ ε^a multiplies every log-slope y_i = d ln
O_i/d ln ε by the same scalar a — is, under this identification, nothing but
the statement that rescaling "how many map-applications count as one unit"
rescales every x_i = ln λ_i/ln b by the reciprocal of that unit, uniformly,
because every x_i shares the same denominator ln b. **The residue — the ray
[y] ∈ ℝP^{n−1}, or D8's Grassmannian point for m controls — is therefore the
projectivized eigenvalue vector of DT(x*), restricted to the eigendirections
the chosen observables probe.** This is C1, and it is an identity given the
standard RG linearization picture D7's own hypotheses already assumed without
naming it: D7 required only that O_i be "a function on the family," which is
exactly what a linear (to leading order) functional of an eigenperturbation is.

**This also explains D8's genuinely fixed-point-free case (its support-type
leg, §P8).** D8 found the Grassmannian construction works even where "there is
no fixed point and no scaling field to appeal to," which looks like tension
with C1. It is not: C1 only requires observables that are homogeneous of some
degree in the approach parameter, which does not require a literal RG fixed
point to arrange — a germ Φ = A|y|^{q1} + B|y|^{q2} has homogeneous behaviour
near y = 0 by direct Taylor/normal-form structure, with no map T needed to
produce it. **C1 identifies the residue with eigenvalue data whenever a
literal description map with a fixed point generates the family; it does not
claim every homogeneous approach must come from one.** The two constructions
(D7/D8's, and the RG-linearization one here) agree wherever both apply and are
independently well-defined where only one does — which is why neither D7 nor D8
needed RG language to get their results right.

## 3. C2 — an exact, infinite-dimensional fixed-point set (proved, not measured)

The clearest available literal description map is the one D3-ladder-invariance
already used without naming: the **dyadic renormalized-sum operator**

```
        T :  law of X   |->   law of (X_1 + X_2)/sqrt(2),   X_1, X_2 iid ~ X
```

This is exactly the setting of Jona-Lasinio's renormalization-group treatment
of the central limit theorem (Phys. Rep. 352 (2001) 439) and its generalized-CLT
continuation (Calvo, Cuchí, Esteve & Falceto, J. Stat. Phys. 141 (2010) 409):
**T's fixed points, up to scale, are the Lévy stable laws**, and the Gaussian is
the fixed point reached from any finite-variance starting law.

**Claim.** For *any* law of a positive random variable U, independent of
Z ~ N(0,1), the scale mixture X = U·Z is an *exact* fixed point of the
n-fold (not just dyadic) version of T — the map "aggregate n iid copies," with
no rescaling-by-√n needed to state the fixed-point property of the *shape*,
because the shape reproduces itself exactly at every n once normalized by √n.

*Proof.* Let X_1, …, X_n be n iid copies of X = U·Z, i.e. n iid pairs (U_i,
Z_i) with X_i = U_i Z_i. This is **not** D3's construction (which shares one U
across the whole aggregate) — see the note below. For the shared-U version D3
actually used: draw one U, then n iid Z_1, …, Z_n ~ N(0,1), and set

```
        S_n  =  U * (Z_1 + ... + Z_n).
```

Since Z_1 + … + Z_n ~ N(0, n) exactly (Gaussians are themselves the trivial
fixed point of ordinary convolution) and U is independent of the Z_i,

```
        S_n  =_d  U * sqrt(n) * Z'      (Z' ~ N(0,1), independent of U)
             =_d  sqrt(n) * (U * Z')
             =_d  sqrt(n) * X
```

for *every* n ≥ 1, where "=_d" is equality in distribution. **The law of
S_n/√n is exactly the law of X, for every n and for every law of U.** ∎

Consequently, for any positively-homogeneous scale statistic s (s(c·Y) = c·s(Y)
for c > 0 — every quantile spread has this property exactly),

```
        s(S_n)  =  sqrt(n) * s(X)        for every n, exactly.
```

**So H = d ln s(S_n)/d ln n = 1/2, exactly, for every n and for every law of
U.** The U-family is an explicit, infinite-dimensional continuum of distinct
laws (different U ⟹ different S_n shape at fixed n, in general — see §4) that
are all *simultaneously* exact fixed points, in the shape sense above, of the
same aggregation map, and all share the identical scale eigenvalue 1/2. This is
proved here; §4 of the experiment README checks it numerically against an
estimator that does not assume it.

**Why this is a genuine instance of D7's construction, not a fourth
unrelated one.** Treat "domain A's observable" and "domain B's observable" (D3's
own framing) as two functions of the *same* shared control n; D7's ray
construction applies to any finite list of observables against one control,
regardless of whether they come from "one system" or "two systems compared
through a shared control." D3's ratio r = H_B/H_A is D7's y_1/y_2 for the pair
(O_1, O_2) = (s_A(n), s_B(n)). This was already the reading recorded in
`SYNTHESIS.md`'s branch-reconciliation pass ("a fourth ratio of the same
shape"); C1–C2 supply the reason it had to come out that way.

## 4. C4 — what the residue cannot see, and why (the falsifiable core)

If C1–C2 are right, the residue construction extracts *only* the eigenvalue
data of DT(x*) along whichever directions the chosen observables probe. Any
direction **tangent to the fixed-point set itself** — i.e. any parameter that
moves you from one fixed point to another *without* changing the leading
eigenvalue — is invisible to it by construction, no matter how many
scale-homogeneous observables are added, because such a direction contributes
nothing to any observable's *log-slope against the control*: by definition, a
quantity that is exactly n-invariant along the whole fixed-point set has zero
log-slope, so it never enters the y-vector at all. Recovering it requires a
different kind of measurement entirely — comparing two members of the family
directly, not describing one member's approach to itself.

In the U-family this direction is realized concretely: the **shape** of X = UZ
(its kurtosis, its tail weight — anything expressible as a ratio of quantile
spreads, hence scale-invariant, hence H ≡ 0 by construction) varies with the
law of U, while the **scale eigenvalue** (H = 1/2) does not, for any U. The
tangent space to this particular fixed-point set is therefore literally
"all the ways X can look, holding its self-similarity index fixed" — an
infinite-dimensional space (all laws of U), of which D3's single lognormal
example was one point.

**This is why D3's counterexample was not a special coincidence.** It is the
generic behaviour of a residue construction applied to a fixed-point set with
positive-dimensional tangent directions — exactly the situation
[the register itself names](../questions/UNKNOWN-LAWS.md) via two established
RG analogues (§0 of the pre-registration): lines of fixed points from an
exactly marginal operator, and CFT conformal manifolds. Neither is an exact
match — the U-family needs no marginal-operator machinery or supersymmetric
protection, it is elementary — but both confirm the phenomenon (some invariant
data staying fixed across a family of genuinely different theories) is a known
feature of fixed-point sets with moduli, not a special property of this one
construction.

## 5. Where D10 fits, and why it is not a fourth account

D10 answers a different question from C1–C4: not *what the residue is*, given
that a chart is free to move, but *which variables have a chart free to move at
all*. Its criterion — a chart is pinned to G_diff when its variable is additive
under system composition ⊎, or dual to one — determines whether there is
anything for the eigenvalue construction to quotient by in the first place.

In the setting used here, this can be checked directly rather than assumed.
The control **n** (an aggregate count) is additive under concatenation: n₁
items followed by n₂ more is n₁ + n₂ items, with no ambiguity about what
"composing two aggregates" means. By D10's C3, its chart is therefore pinned,
and H = 1/2 is a **fact** about this construction, not a gauge-dependent
number — exactly matching
[the first D3 run](../experiments/D3-ladder-as-quotient/)'s independent finding
that this harness's chart is pinned by additive aggregation. The **value axis**
x carries no such composition meaning — there is no operation "compose two
draws' *values*" that concatenation supplies — so its chart is free (G_pow),
which is exactly what
[D3-ladder-invariance](../experiments/D3-ladder-invariance/)'s P2/P5 already
measured (H moves by exactly a factor of a under x ↦ sign(x)|x|^a; the ratio
does not).

**So D10 is not a competing description of the residue. It is the
precondition that decides whether C1–C4's construction has anything nontrivial
to quotient by, applied here to a variable (an aggregate count) the register
had not yet used it on.** The four results are consistent because they were
never actually about the same question.

## 6. Verdict

**The three accounts reconcile, in the setting they share.** D7/D8 compute the
projectivized eigenvalue spectrum of a description map's linearization at a
fixed point. D10 determines which variables carry that structure at all. D3's
"fixed point, ratio as eigenvalue" language is the standard RG/probabilistic
frame for exactly what D7/D8 compute — and its counterexample is not an
anomaly but the generic signature of a fixed-point set with tangent directions,
which is now a provable, not merely observed, boundary of the whole
construction: **the residue is exactly blind to whatever is tangent to the
fixed-point set, and no amount of adding more same-kind observables (more
scale-homogeneous functions of the same control) can recover it.**

**Honest scope.** Checked in one setting: single control, an explicit linear
(convolution) description map with an exactly-solvable, infinite-dimensional
fixed-point set. Not checked: D8's m > 1 Grassmannian case under a literal
description map (only D7's m = 1 slice is used here); a description map with
genuine nonlinear dynamics, where the fixed-point set's tangent directions are
not available in closed form and the C1 identification would need to be
approximate rather than exact; whether *every* floor-3 germ's residue
construction (D2, D6's) admits a literal description-map reading, or only
admits the weaker "homogeneous by direct Taylor structure" reading D8's
support-type leg already showed suffices without one. **The experiment's two
observables are both quantile spreads — the same scaling type, hence
trivially the same eigenvalue — so C3 tests estimator fidelity against a
*known* value, not a nontrivial eigenvalue ratio; C1's ratio-of-eigenvalues
reading rests on the already-tested nontrivial cases (D2's β/k, D6's q1/q2,
P-D's θ), not on anything newly measured here.** Graded honestly, per §0
of the pre-registration: **N1** — a recombination of already-known results,
correctly composed, with one derived (not previously stated in this repo or,
so far as the prior-art search found, in the literature) consequence: the
residue's blindness to fixed-point-tangent directions is a *provable* general
fact about the construction, not a property discovered once by accident.
